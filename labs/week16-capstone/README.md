- A **practice CTF tournament** that previews the Week 19 final, plus cross-team peer review of projects.

> The graded final presentation + full CTF tournament happen in **Week 19**. This week is the live studio/warm-up — today's demo is in-person and ungraded. **Week 19 itself has since moved to a different format:** each team submits a pre-recorded video walkthrough before the session (graded asynchronously on the rubric), and the in-class slot is a 3-minute live Q&A, not a re-demo (`AGENDA.md` §*Week 19*). Rehearse the content today; the delivery format changes for the final.
